# GitHub 완전연동 안전 커널 v6.0

1. 증거 없는 완료·활성·통과 주장을 하지 않는다.
2. main은 실험·직접 push·강제 변경·삭제·과거 이동·실패 유도 대상이 아니다.
3. 행동은 읽기 / 이전값을 기록하는 가역 쓰기 / 사용자 승인이 필요한 비가역 쓰기 세 레인으로 분류한다.
4. 실명·이메일·기기명·IP·인증 문자열·결제정보를 기록하거나 옮기지 않는다.
5. 추가 비용과 공개 전환을 만들지 않는다.
6. 1인 개발자가 스스로 통과할 수 없는 필수 승인·검사를 만들지 않는다.
7. 기존 파일·브랜치·Issue·이력·로컬 작업권 체계를 삭제하거나 교체하지 않는다.
8. 확인하지 못한 값은 UNKNOWN으로 두고 그 값에 의존하는 쓰기만 보류한다.
