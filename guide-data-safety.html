Data Safety Guide

내 노트를 잃지 않는 현실적인 방법

로컬 우선 앱은 빠르고 개인적이지만, “내 기기에 있다”와 “영원히 안전하다”는 같은 말이 아닙니다. 브라우저 데이터 삭제, 기기 분실, 저장장치 고장에 대비해 복구 경로를 직접 확인해야 합니다.

핵심: 중요한 노트는 앱 안의 한 사본만 믿지 말고, 정기적으로 내보내고 실제 복원을 시험하세요.

로컬 저장이 의미하는 것

노트플러스P의 편집 데이터는 기본적으로 사용 중인 브라우저 저장공간에 머뭅니다. 같은 컴퓨터라도 다른 브라우저나 다른 사용자 프로필에서는 보이지 않을 수 있습니다. 시크릿 모드나 자동 정리 도구는 종료 때 데이터를 지울 수 있어 장기 보관에 적합하지 않습니다.

브라우저 기록 삭제에서 사이트 데이터까지 선택하거나 운영체제를 초기화하면 노트가 사라질 수 있습니다. 따라서 브라우저 저장은 작업 사본으로 보고, 내보낸 파일을 복구 사본으로 관리하는 편이 안전합니다.

3-2-1 방식으로 사본을 나눕니다

중요한 자료는 최소 세 사본을 두고, 두 종류의 저장 매체에 나누며, 한 사본은 다른 장소에 둡니다. 예를 들어 현재 브라우저의 작업 사본, 외장 저장장치의 내보내기 파일, 신뢰하는 클라우드의 암호화된 복사본을 함께 유지할 수 있습니다.

파일명에는 날짜와 범위를 넣고 덮어쓰기보다 여러 세대를 남기세요. 가장 최근 파일 하나만 있으면 손상이나 실수도 그대로 복제될 수 있습니다.

백업은 복원 시험까지 해야 완성됩니다

  1. 중요하지 않은 시험 노트를 하나 만듭니다.
  2. 내보내기 파일을 만들고 크기가 0이 아닌지 봅니다.
  3. 가능하면 별도 브라우저 프로필이나 시험 환경에서 가져옵니다.
  4. 제목, 본문, 날짜, 첨부를 실제로 엽니다.
  5. 시험 날짜와 결과를 기록하고 다음 점검일을 정합니다.

대량 자료는 전체 노트 수뿐 아니라 여러 형식의 표본을 확인해야 합니다. 오래된 백업도 앱 형식이 바뀔 수 있으므로 분기마다 한 번 정도 복원 연습을 권합니다.

기기를 바꾸기 전 확인할 것

기존 기기에서 최신 백업을 만들고 두 곳에 복사한 뒤, 새 기기에서 복원이 끝날 때까지 기존 기기를 초기화하지 마세요. 새 환경에서 결과를 확인하고 다시 백업한 후에만 이전 기기를 정리합니다.

공용 PC와 공유 기기

공용 기기에서는 개인 노트를 작성하거나 백업 파일을 내려받지 않는 것이 가장 안전합니다. 꼭 사용해야 한다면 로그아웃만으로 충분하다고 가정하지 말고 파일 다운로드 폴더와 브라우저 사이트 데이터까지 직접 확인합니다.

사고가 났을 때

새 데이터를 계속 쓰면 복구 단서를 덮을 수 있습니다. 먼저 현재 화면과 오류를 기록하고, 브라우저 프로필과 백업 파일을 복사한 뒤 복원 시험은 복사본으로 진행하세요.
