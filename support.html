문제가 생겼을 때 먼저 확인하세요

노트가 보이지 않을 때

마지막으로 사용한 것과 같은 기기, 브라우저, 브라우저 프로필인지 확인합니다. 시크릿 창이나 다른 프로필은 별도 저장공간을 사용합니다. 브라우저 데이터를 지우기 전에 남아 있는 화면과 백업을 먼저 보존하세요.

가져오기가 멈출 때

원본을 삭제하지 말고 더 작은 묶음으로 시험합니다. 파일 형식, 크기, 실패 시각, 화면에 나온 경고를 기록하세요. 대용량 첨부는 저장공간 부족의 원인이 될 수 있습니다.

기기를 바꿀 때

기존 기기에서 최신 백업을 두 곳에 만든 뒤 새 기기에서 복원 결과를 확인하세요. 확인 전에는 기존 기기를 초기화하지 않습니다.

광고가 비어 있거나 이상할 때

광고는 Google의 사이트 승인, 지역, 동의, 광고 재고와 브라우저 설정에 따라 표시되지 않을 수 있습니다. 광고 차단기를 끄거나 실제 광고를 클릭하도록 요구하지 않습니다. 광고가 메뉴나 앱 버튼을 가린다면 화면 크기와 페이지 주소를 기록해 주세요.

문의에 포함하면 좋은 정보

  • 문제가 난 페이지 주소와 시각
  • 기기 종류, 운영체제, 브라우저와 버전
  • 재현 순서와 화면의 정확한 문구
  • 개인정보를 가린 화면 캡처

노트 원문, 비밀번호, 로그인 토큰, 전체 백업 파일은 공개 문의에 첨부하지 마세요.
